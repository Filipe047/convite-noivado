# Fotografias dos momentos do casal

Coloque aqui três imagens com estes nomes:

- `moment-01.jpg`
- `moment-02.jpg`
- `moment-03.jpg`

O site mostra automaticamente um carrossel com fade in/out. Se uma imagem ainda não existir, aparece um espaço reservado com o nome do ficheiro esperado.

Pode usar JPG, PNG ou WebP, mas se alterar a extensão também deve atualizar os caminhos em `src/main.js`.

Recomendação: imagens horizontais, com pelo menos 1200 px de largura e tamanho comprimido para carregamento rápido.
